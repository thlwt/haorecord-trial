# 好記錄（HaoRecord）— 試用版

台灣工地、巡查、點交用的**現場記錄表**工具：拍照 → 一行說明 → 簽名 → 按一個鍵出 A4 PDF。

**這個 repo 只放已編譯的試用版與說明文件，不含原始碼。**

## 下載

到 [Releases](../../releases/latest) 下載 `HaoRecord-Trial-1.8.0.exe`（Windows 免安裝，雙擊就開）。

## 這一版（1.8.0 試用版）

- **只輸出 PDF**：列印 → 另存 PDF，就是可交付的成品
- **不產生 md／JSON／CSV**，所以也**不能匯入**把內容讀回來改
- **沒有使用期限**、**沒有水印**
- 版本徽章：`V1.8.0 試用版｜頭號老玩童THLWT`

## 主要功能

- 照片日期讀 **EXIF**（拍攝時間），系統另蓋**建檔時間**，兩個都留
- 一頁 2／3／4 組版面可選，每頁自己的頁碼與日期
- 簽名欄可改名（工地主任／安衛／監造⋯⋯），滑鼠或手指直接簽進 PDF
- 自訂欄位（文字／數字／下拉選單），可上色
- iPhone HEIC、相機 RAW、TIFF 都能開，轉檔在本機做，**不上傳**
- PDF 頁尾附**內容指紋**：同一份記錄改一個字就對得出來
- 完全離線，資料存在你自己的電腦

## 限制（先講清楚）

- 沒有雲端、不上傳
- 不能多人同時編輯
- 手寫簽名與指紋**不是電子簽章**，能不能當證據請依所在地法律自行評估
- 資料只在你的電腦，硬碟壞了就沒了——重要的表請輸出 PDF 留存

Windows 10／11（64-bit）。
